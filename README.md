# Memory Game
Memory Game - это популярная игра на развитие внимания и памяти: игроку необходимо найти все пары карточек за минимальное количество ходов.

## Правила игры

1. Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы. Все 16 карточек перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найденных пар — 0 из 8. Игрок сразу может открывать карточки.
2. Игрок открывает одну карточку, затем другую. **Один ход — открытие двух разных доступных карточек**, независимо от того, совпали они или нет.
3. Если изображения совпали, обе карточки остаются открытыми до конца игры. Счётчик найденных пар увеличивается на 1.
4. Если изображения различаются, обе карточки остаются видимыми 1.5 секунды, затем закрываются. Пока игрок рассматривает несовпавшую пару, открыть другие карточки нельзя.
5. Когда найдены все 8 пар, игра завершена. Автоматически открывается модальное окно с сообщением о победе, итоговым количеством ходов и кнопками «New game» и «Close».
6. В хедере расположены кнопки «New game» и «Leaderboard». «New game» начинает игру заново: карточки перемешиваются и закрываются, счётчики обнуляются. «Leaderboard» открывает сохранённые результаты в модальном окне.

Интерфейс на английском языке.

## Запуск игры

Игру можно запустить в браузере или локально

### Запуск в браузере

[Memory Game](https://anastasiya-y.github.io/memory-game/)

### Локальный запуск
1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/Anastasiya-Y/memory-game.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd memory-game
   ```

3. Переключиться на рабочую ветку:

   ```bash
   git checkout memory-game
   ```

4. Установить зависимости:

   ```bash
   npm install
   ```

5. Запустить проект:

   ```bash
   npm start
   ```

6. В браузере должен автоматически открыться проект. Если этого не произошло, открыть в браузере адрес, который выведет консоль:

   ```
   http://localhost:8080
   ```
